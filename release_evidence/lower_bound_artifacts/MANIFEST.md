## Handling values

- `unchanged`: the included bytes are the pack record bytes, so the included digest equals the pack record digest.
- `paths replaced`: internal paths, private addresses and machine names read as tokens such as `<path>` and `build-host`. The included digest differs from the pack record digest; both are listed.
- `tokens replaced`: interpreter names and paths read `<interp>`, an interpreter version reads `<interp-version>` under the key `interpreter`, thread, worker and process counts read `<threads>`, core lists and core counts read `<cores>`, and memory figures read `<memory>`. The included digest differs from the pack record digest; both are listed. The bytes before replacement are held in the withheld set.
- `paths and tokens replaced`: both replacements apply.
- `extract`: the pack record is a source extract published in `proofs/certificates/lower_bounds/extracts`. The published bytes can differ from the pack record (see `proofs/certificates/lower_bounds/extracts/README.md` there); the included digest is the digest of the published bytes.
- `binary`: a compiled search executable; see below.

## Withheld tokens

This folder holds two kinds of file. RECORDS are the 270 included files in `release_evidence/lower_bound_artifacts/files/` and the logs, receipts and JSON result files of the other folders. A record keeps its recorded content byte for byte. Where a label, a key name or a word of a record may not be public, only an explicit token replaces it: `<label withheld>`, `<key withheld>` or `<word withheld>`. Nothing else of a record differs from its source: `release_evidence/lower_bound_artifacts/files/` equals its sources for 270 of 270 files. DOCUMENTS are `MANIFEST.md`, `COUNT_RECONCILIATION.md`, `SU15_L6_BINARY.md`, the `note` text inside the `MANIFEST.json` files, and the README files of the evidence folder. A document is text written for the release.
