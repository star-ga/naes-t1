# su15 level 3: how to re-run the checks

Start with `RECORD.md` (the record), then the withheld independent check record (digest a82bf8e57cd5bf869a8ee2a6f9764323174a933290daaff77ac0332e2ad9b971) (the result of the independent check) and the two proofs `proofs/certificates/su15_L3/p1/PROOF.md` and `proofs/certificates/su15_L3/p2/PROOF.md`. The withheld check note (digest 5c5eb614be4d5479b10c50d3616522d3e38f9068f7b21660fed744bea510b104) is the adversarial check.

Game files. The scripts that use the real engine read the game from the relative folder `games`. Put the game file in the folder `games`, in the subfolder `su15`, in its subfolder `1944f8ab`, under the name `su15.py` (its sha256 is `a5f91f7c963d6ca6447dae0ab21342b48a3f511601c40dfa8e972bdc59b4651e`, and every run checks it). That game file is not included in this release. `proofs/certificates/su15_L3/p2/eng.py` reads the folder from the variable `SU15_GAMES`.
Certificates. The scripts read the route of a level from the file `su15_L<n>.json` of the folder given by `CERT` (default `certificates`). In this pack these files are in the folder `proofs/certificates/levels/`, for example `proofs/certificates/levels/su15_L3.json`. `proofs/certificates/su15_L3/p2/eng.py` reads this folder from `SU15_CERT`.
Vectors. `proofs/certificates/su15_L3/p2/gen_vectors.py` writes the test vectors (about 95 MB). They are not in this folder.
Shared library. `librsim.so` is a compiled helper. It is not included. It is identified by sha256 `25306cd089744fa8574dee4f1805943c5709370f238fbeb8875795ce1e2640ca` and by size 15656 bytes. The source file is `proofs/certificates/su15_L3/check/src/rlib.c` (it includes `rsim.h`). The build command, from the folder `proofs/certificates/su15_L3/check/src/`, is `gcc -O2 -shared -fPIC -o librsim.so rlib.c`.
