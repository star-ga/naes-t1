# Complete cyclic-track token configurations

The archived lp85 grouped-click model retains the ordered list of every button under a click. Each button applies its own track permutation sequentially, so shared-cell transfers and overlapping button groups are preserved. Every goal token follows the same permutation independently of token identity. The native winning condition reads only whether each fixed piece has a matching goal token under its target point.

The replay adapter derives the model from the pinned public game after its canonical earlier-level witnesses. It classifies all 4096 display click pixels and checks that every non-no-op ordered button effect is represented in the archived action alphabet. The original breadth-first search exhausts every shallower token configuration before its first winning configuration. A capped search is rejected. The resulting path is then replayed on the native target instance and must first complete at the computed bound.

The lower-bound theorem requires token-state sufficiency, the stated sequential permutation correspondence, and elimination of non-button/no-op inputs. These remain explicit archived source obligations. The complete pixel-alphabet check and native witness are fresh controls, not a replacement for those universal arguments. No inverse-action pruning or simultaneous-map replacement is added.
